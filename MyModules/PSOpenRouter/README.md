# PSOpenRouter

A PowerShell module for interacting with OpenRouter API.

## What's Included

- `Invoke-OpenRouterChat`: Sends a chat request to the OpenRouter API.

## Using Free OpenRouter Models

Check out the [OpenRouter free model collection](https://openrouter.ai/collections/free-models) to experiment with free models.
In the `-Model` parameter, paste in the model name from the site.
Example: `-Model poolside/laguna-s-2.1:free`
