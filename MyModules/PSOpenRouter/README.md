# PSOpenRouter

A PowerShell module for interacting with OpenRouter API.

## What's Included

- `Invoke-OpenRouterChat`: Sends a chat request to the OpenRouter API.

## Future Plans

- [ ] Ability to work with other APIs, not just OpenRouter
- [ ] Add option to send multiple messages instead of just one.
- [ ] Explore the `"role"` parameter for chat requests.
